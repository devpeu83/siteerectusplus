# Images Directory

This directory contains image assets for the Site Erectus Plus project.

## Organization

Organize images by type or feature:

```
images/
├── logos/          # Brand logos and icons
├── backgrounds/    # Background images
├── icons/          # UI icons
└── content/        # Content images
```

## Guidelines

- Use descriptive filenames (e.g., `hero-banner.jpg` instead of `img1.jpg`)
- Optimize images for web before adding them
- Use appropriate formats:
  - `.jpg` for photographs
  - `.png` for graphics with transparency
  - `.svg` for icons and logos
  - `.webp` for modern browsers with fallbacks

## Image Optimization

Consider using tools like:
- ImageOptim
- TinyPNG
- Squoosh
- ImageMagick

## Attribution

Remember to:
- Keep track of image sources
- Include proper attribution for stock photos
- Respect copyright and licensing
